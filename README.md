# COURIER.EXE

## Premissa

Invada uma rede digital controlada por grandes corporações. Encontre o terminal, quebre a criptografia e entregue os Dados antes dos seus adversários.

Assim que os dados forem obtidos, corra para realizar a entrega antes dos seus adversários. Mas cuidado com os obstáculos que iram aparecer no seu caminho.

Quebre a criptografia, seja rápido e entregue os dados antes dos seus adversários.

#### Nomenclatura

##### Courier:

É o jogador responsável por invadir a rede, recuperar o Data Core e transportá-lo até o ponto de extração.

##### Crypto Break:

É o pequeno desafio de criptografia que precisa ser resolvido para desbloquear o Data Core.

##### Terminal:

É o equipamento espalhado pelo mapa onde o jogador encontra o acesso ao Data Core.

##### Extraction Point:

É o ponto de extração para onde o portador precisa levar o Data Core para vencer.

#### Personagens

(OBS: É um jogo multiplayer de 2 a 4 jogadores. Não existem personagens com estilos, personalidades ou habilidades próprias. O que diferencia os jogadores são as cores escolhidas antes da partida.)

O primeiro jogador poderá escolher entre todas as cores disponíveis, o segundo terá as opções restantes e assim sucessivamente.

Cores (roupa/cabelo):

-Roxo
-Vermelho
-Branco

#### Mapa

##### Network District

A cidade representa uma região da rede digital controlada por uma grande corporação.

O mapa possui uma visão superior (top-down) 2D e é construído para permitir que todos os jogadores tenham diversas opções de rota.

Existem corredores, áreas abertas, atalhos, obstáculos e terminais  espalhados pela arena.

O mapa precisa ser fácil de compreender visualmente, mas possuir rotas suficientes para criar perseguições e decisões estratégicas.

A localização dos dados não deve ser conhecida imediatamente pelos jogadores.

Todos começam em pontos diferentes da arena e precisam explorar o mapa para encontrar o Terminal.

## Funcionamento

### A Mecânica Principal

O grande diferencial do Courier.exe é a mudança de objetivo durante a partida.

Inicialmente, todos os jogadores estão procurando o mesmo objetivo.

O jogador consegue desbloquear os dados e os robôs passam a persegui-lo, o objetivo se torna chegar ao servidor antes dos seus adversaŕios sem ser impedido.

#### O jogo possui três momentos principais:

##### 1. Localização:

Os jogadores exploram a cidade procurando pelo Terminal.

##### 2. Criptografia:

Após o jogador encontrar o Terminal precisa resolver o Crypto Break para desbloquear os dados.

##### 3. Fuga:

Após obter os dados, o jogador precisa chegar ao servidor antes dos outros jogadores, sem ser interceptádo.

### Crypto Break

Ao interagir com o Terminal, o jogador encontra uma criptografia simples.

O desafio pode utilizar:

°Sequências numéricas

°Códigos

°Combinações

#### O Risco:

Enquanto um jogador está resolvendo o Crypto Break, os seu adversários continuam livres para chegar a outros Terminais e resolverem o Crypto Break também.

Caso o jogador erre, poderá tentar novamente.

### A Disputa Pelo Data Core

O jogador que resolver corretamente a criptografia obtém os dados.

### A Fuga

O jogador que possui os dados precisa chegar ao servidor.

O portador deve escolher sua rota enquanto tenta evitar os obstáculos.

### Interceptação

Quando os robos conseguem alcançar o portador, os dados podem ser perdidos.

se o jogador perder ele renace e recomeça a missão do zero.

## Estilo de Partida

### Duração:

Partidas rápidas de aproximadamente 3 a 6 minutos.

### Ritmo:

A partida começa com exploração e raciocínio, evolui para uma disputa e termina em uma perseguição de alta velocidade.

### Sensação:

A sensação desejada é de estar participando de uma invasão em uma "cidade" digital.

Primeiro o jogador precisa pensar.

Achar o codigo. 

Quebrar a criptografia.

Depois correr.

Por fim, precisa escapar e realizar a entrega de dados.

O jogo deve transmitir tensão, velocidade e competitividade sem possuir regras excessivamente complexas.

## Objetivo

O objetivo do jogador é encontrar o Terminal, resolver a criptografia, obter o Data Core e realizar a extração antes dos adversários.

O jogador precisa utilizar:

°Raciocínio

°Reflexos

°Velocidade

°Conhecimento do mapa

°Estratégia
